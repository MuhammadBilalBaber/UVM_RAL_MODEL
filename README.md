**Description**
This project implements a simple DUT (Design Under Test) containing four memory-mapped registers that support basic read and write operations.
To verify the functionality of these registers, a complete UVM Register Abstraction Layer (RAL) Model has been developed.

The purpose of this setup is to demonstrate how to:

=> Build a small DUT using memory-mapped registers

=> Create and integrate a UVM RAL model

=> Use RAL sequences to validate correct read/write behavior

=> Understand the flow of register transactions in a UVM-based verification environment
